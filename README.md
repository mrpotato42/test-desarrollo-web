# PAUSA POP

Sitio web estático de una tienda de juguetes sensoriales Pop-it. Incluye un catálogo en carrusel y un carrito que conserva los productos en el almacenamiento local del navegador.

## Estructura

- `src/index.html`: estructura y contenido de la página.
- `src/styles.css`: estilos generales y diseño responsive.
- `src/script.js`: interacción del menú y conexión de los botones de producto.
- `src/components/cart/`: componente y estilos del carrito.
- `src/components/product-carousel/`: componente y estilos del carrusel.
- `public/`: imágenes utilizadas por el sitio.

## Uso

Abre `src/index.html` en un navegador. No se requieren dependencias ni proceso de compilación.
